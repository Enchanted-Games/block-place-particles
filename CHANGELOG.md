# 0.10.0-alpha.2

This version comes with an absolute ton of internal changes, I don't expect anything to be majorly broken but a couple features haven't been extensively tested yet. As always please be sure to report any bugs you find!

## Fixes in alpha 2
- Fixed underwater bubble particles gaining way too much vertical speed
- Fixed underwater bubble particles appearing above the surface of the water before popping
- Fixed honey drop particles floating above the ground when landing
- Leaf litter once again has leaf particles instead of vanilla ones
